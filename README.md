TEC — Learn C. Think Deeper. Build Anything.

A little project that started with a simple task: learn C programming.

Instead of just going through tutorials and documentation, I thought, why not make learning a little more interesting?

So I decided to build my own interactive C learning website using Google Antigravity, and then use that website to learn C myself.

I also wanted to tinker around with Node.js and explore web development along the way. TEC became a way to experiment, learn new things, and build something useful at the same time.

That's pretty much how TEC started!

🌱 What's TEC?

TEC is an interactive website designed to make learning C programming a little less boring and a lot more hands-on.

The idea is simple: learn a concept, understand how it works, take a quiz, and try writing some code yourself.

I'm using a Markdown file containing my C programming guide as the foundation for the lessons. The goal is to turn that guide into an actual learning experience rather than just reading through a document.

✨ What I'm Building
📚 Structured lessons — Learn C step by step, from the basics to more advanced concepts.
🧠 Interactive quizzes — Test what you've learned with MCQs, true/false questions, and code-output challenges.
💻 Coding playground — Write and experiment with C programs directly on the website.
📈 Progress tracking — Keep track of completed lessons, quiz scores, and learning progress.
🔖 Bookmarks and notes — Save useful concepts and snippets for later.
🔍 Search — Quickly find lessons, topics, and programming concepts.
🌙 Dark mode — Because dark mode is a necessity, not a feature.
🎨 A Little About the Design

I wanted the website to have a clean, minimal look, taking inspiration from Apple's design language.

Soft gradients and subtle glass effects.

A simple interface that doesn't distract from learning.

🚀 Running Locally

Want to try it out?

Make sure you have Node.js and npm installed.

1. Clone the repository

bash
git clone https://github.com/YOUR-USERNAME/tec-c-learning.git


2. Navigate into the project

bash
cd tec-c-learning


3. Install dependencies

bash
npm install


4. Start the development server

bash
npm run dev


Open the local URL shown in your terminal (usually http://localhost:5173).
